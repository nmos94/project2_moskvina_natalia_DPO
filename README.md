# Primitive Database

Простая примитивная база данных на Python с возможностью управления таблицами.

## Описание

Primitive Database - это учебный проект, реализующий базовую систему управления базами данных с поддержкой создания и удаления таблиц. Метаданные о структуре таблиц хранятся в JSON-файле.

## Управление таблицами

### Создание таблицы

**Синтаксис:**
```
create_table <table_name> <column1:type1> <column2:type2> ...
```

**Поддерживаемые типы данных:**
- `int` - целые числа
- `str` - строки
- `bool` - логические значения (true/false)

**Особенности:**
- Столбец `ID:int` добавляется автоматически в начало таблицы, если не задан пользователем
- Если вы хотите использовать свой столбец ID (например, `ID:str`), можете указать его явно
- Имя таблицы должно быть уникальным

**Примеры:**
```
# Создание таблицы без ID (добавится автоматически ID:int)
>>>Введите команду: create_table users name:str age:int active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, active:bool

# Создание таблицы с собственным ID
>>>Введите команду: create_table products ID:str title:str price:int
Таблица "products" успешно создана со столбцами: ID:str, title:str, price:int

# ID в любом регистре
>>>Введите команду: create_table articles id:int title:str content:str
Таблица "articles" успешно создана со столбцами: id:int, title:str, content:str
```

**Результат:**
```
Таблица 'users' успешно создана
```

### Удаление таблицы

**Синтаксис:**
```
drop_table <table_name>
```

**Примеры:**
```
# Удаление таблицы пользователей
db> drop_table users
```

**Результат:**
```
Таблица 'users' успешно удалена
```

## CRUD операции (работа с данными)

После создания таблиц вы можете работать с данными внутри них.

### Вставка данных (INSERT)

**Синтаксис:**
```
insert into <имя_таблицы> values (<значение1>, <значение2>, ...)
```

**Особенности:**
- ID генерируется автоматически
- Количество значений должно соответствовать количеству столбцов (без ID)
- Строковые значения указываются в кавычках: `"текст"`
- Булевы значения: `true` или `false`
- Числовые значения без кавычек

**Примеры:**
```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: insert into users values ("Anna", 25, true)
Запись с ID=2 успешно добавлена в таблицу "users".
```

### Чтение данных (SELECT)

**Синтаксис:**
```
select from <имя_таблицы>                          # Все записи
select from <имя_таблицы> where <столбец> = <значение>  # С условием
```

**Примеры:**
```
>>>Введите команду: select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
| 2  |  Anna  | 25  |    True   |
+----+--------+-----+-----------+

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+
```

### Обновление данных (UPDATE)

**Синтаксис:**
```
update <имя_таблицы> set <столбец> = <новое_значение> where <столбец> = <значение>
```

**Особенности:**
- Можно обновлять несколько столбцов: `set age = 29, name = "John"`
- WHERE условие обязательно

**Примеры:**
```
>>>Введите команду: update users set age = 29 where name = "Sergei"
Обновлено записей: 1 в таблице "users".

>>>Введите команду: update users set is_active = false where age = 25
Обновлено записей: 1 в таблице "users".
```

### Удаление данных (DELETE)

**Синтаксис:**
```
delete from <имя_таблицы> where <столбец> = <значение>
```

**Примеры:**
```
>>>Введите команду: delete from users where ID = 1
Удалено записей: 1 из таблицы "users".

>>>Введите команду: delete from users where name = "Anna"
Удалено записей: 1 из таблицы "users".
```

### Информация о таблице (INFO)

**Синтаксис:**
```
info <имя_таблицы>
```

**Пример:**
```
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Декораторы и замыкания

Проект использует декораторы для улучшения качества кода и обеспечения безопасности операций.

### @handle_db_errors - Централизованная обработка ошибок

Декоратор автоматически перехватывает и обрабатывает ошибки базы данных:
- `FileNotFoundError` - файл данных не найден
- `KeyError` - таблица или столбец не найден
- `ValueError` - ошибки валидации данных
- `Exception` - непредвиденные ошибки

Применяется к функциям: `create_table`, `drop_table`, `insert`, `update`, `delete`, `get_table_info`

**Пример работы:**
```
>>>Введите команду: insert into nonexistent values ("test", 1)
Ошибка: таблица "nonexistent" не существует
```

### @confirm_action - Подтверждение опасных операций

Декоратор-фабрика запрашивает подтверждение пользователя перед выполнением опасных операций.

Применяется к функциям:
- `drop_table` - удаление таблицы
- `delete` - удаление записей

**Пример работы:**
```
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
Операция отменена.

>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Удалено записей: 1 из таблицы "users".
```

### @log_time - Измерение времени выполнения

Декоратор измеряет и выводит время выполнения функции.

Применяется к "медленным" операциям:
- `insert` - вставка записей
- `select` - выборка данных

**Пример работы:**
```
>>>Введите команду: insert into users values ("Alice", 30, true)
Функция insert выполнилась за 0.002 секунд
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: select from users
Функция select выполнилась за 0.001 секунд
+----+-------+-----+-----------+
| ID |  name | age | is_active |
+----+-------+-----+-----------+
| 1  | Alice | 30  |    True   |
+----+-------+-----+-----------+
```

### create_cacher() - Кэширование с замыканием

Функция создает кэширующую функцию с использованием замыкания. Кэш хранится в замыкании и доступен только через возвращаемую функцию.

**Возможности:**
- `cache_result(key, value_func)` - получает результат из кэша или вычисляет
- `cache_result.clear()` - очищает весь кэш
- `cache_result.stats()` - возвращает статистику кэша

**Пример использования в коде:**
```python
cache = create_cacher()

# Первый вызов - вычисление
result = cache('users_all', lambda: select(table_data, None))
# [CACHE MISS] Вычисление результата для ключа 'users_all'

# Второй вызов - из кэша
result = cache('users_all', lambda: select(table_data, None))
# [CACHE HIT] Результат получен из кэша для ключа 'users_all'

# Статистика
stats = cache.stats()
# {'size': 1, 'keys': ['users_all']}

# Очистка
cache.clear()
# [CACHE] Кэш очищен
```

```json
{
    "tables": {
        "users": {
            "columns": {

                "name": "str",
                "age": "int",
                "active": "bool"
            }

        "products": {
            "columns": {
                "ID": "int",
                "title": "str",
                "price": "int",
                "in_stock": "bool"
            }
        }
    }
}
```
